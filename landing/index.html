Перевод прямо в чате

Выделите фразу в поле ввода — рядом появится печать. Один клик: иероглифы, пиньинь с тонами, озвучка. Ещё один — и китайский текст стоит на месте русского.

Скачать с GitHub Сайт HONGLONG

Нужен аккаунт HONGLONG. Магазина нет: расширение ставится распакованным.

Один сценарий

Выделил, нажал, вставил

  1. Выделение Любой текст в поле ввода или в переписке. Печать 译 появляется сама.
  2. Карточка Иероглифы киноварью, пиньинь по слогам — каждый тон своим цветом.
  3. Вставка Текст заменяет выделенное прямо в редакторе. Undo работает: Ctrl+Z вернёт русский.

Установка

Пять шагов, без магазина

  1. Скачайте репозиторий: Code → Download ZIP и распакуйте.
  2. Откройте chrome://extensions.
  3. Включите «Режим разработчика» справа сверху.
  4. «Загрузить распакованное расширение» → папка extension.
  5. Войдите на honglong.nexusbots.ru — перевод работает только для аккаунтов.

Честно

Что не работает

Telegram Desktop не поддерживается: расширение живёт в браузере и работает с DOM страницы, а в нативное приложение текст так не вставить. Замена текста зависит от редактора чата — если он игнорирует вставку, карточка положит перевод в буфер. Лимиты те же, что у сайта: суточная квота на аккаунт.
